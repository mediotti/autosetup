# autosetup
This repo (should) store all the necessary files to customize my development environment. My go-to selection of tools are:
- Code Editor: Visual Studio Code;
- DB Client: DBeaver;
- Shell: ZSH (with oh-my-zsh) and Tmux;
- Miscellaneous: Docker, Postman, vim(with nvim);

To setup all those tools, clone the git repo and execute the script with `sudo`:

```bash
sudo ./autosetup.sh
```
